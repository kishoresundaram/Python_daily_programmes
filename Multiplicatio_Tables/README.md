# 🚀 Day 5 – Python Loops

## 📌 Overview

This is my **Day 5** project as part of my **#100DaysOfAI** learning journey.

In this project, I learned how to use Python loops by developing a **Multiplication Table** program. The program accepts a number from the user and generates its multiplication table from 1 to 10 using a `for` loop.

---

## 📚 Topics Covered

- for Loop
- while Loop
- range() Function
- Loop Iteration
- User Input

---

## 💻 Project

### Multiplication Table

The program performs the following tasks:

- Accepts a number from the user
- Uses a `for` loop to iterate from 1 to 10
- Generates and displays the multiplication table

---

## 🖥️ Sample Output

```
Enter the number: 7

***** Multiplication Table *****

7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
7 x 6 = 42
7 x 7 = 49
7 x 8 = 56
7 x 9 = 63
7 x 10 = 70
```
