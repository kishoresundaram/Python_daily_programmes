# 🚀 Day 12 – Expense Tracker

## 📌 Overview

This is my Day 12 mini project as part of my **#100DaysOfAI learning journey**.

I built a simple menu-driven **Expense Tracker using Python** to record expenses, display expense details, calculate total spending, and identify unique expense categories.

## 💻 Project Features

The program provides five options:

1. Add Expense
2. Display Expenses
3. Show Total Expense
4. Show Categories
5. Exit

### Add Expense

Allows the user to enter:

* Expense Name
* Amount
* Category

Each expense is stored as a dictionary inside a list.

### Display Expenses

Displays all recorded expenses with their amount and category.

### Show Total Expense

Calculates the total amount spent using a loop.

### Show Categories

Uses a Python Set to display only unique expense categories.
