# 🚀 Day 1 – Python Basics

## 📌 Overview

This is my **Day 1** project as part of my **#100DaysOfAI** learning journey.

In this program, I learned the fundamentals of Python by creating a simple **Student Record Management** application. The program accepts user input and displays the entered details in a structured format.

---

## 📚 Topics Covered

- Python Introduction
- `print()` Function
- `input()` Function
- Variables
- User Input
- Output Formatting

---

## 💻 Project

### Student Record Management

The program performs the following tasks:

- Accepts the student's name
- Accepts the student's age
- Accepts the student's college
- Accepts the student's department
- Displays a personalized welcome message

---

## 🖥️ Sample Output

```
**** Simple Student Record Management ****

Enter your name: Kishore
Enter your age: 22
Enter your college: ABC College
Enter your Department: Computer Science

Hello, Kishore!

Welcome to ABC College.

You are 22 years old and studying in the Computer Science Department.

Have a great learning journey!
```
