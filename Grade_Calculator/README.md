# 🚀 Day 4 – Decision Making in Python

## 📌 Overview

This is my **Day 4** project as part of my **#100DaysOfAI** learning journey.

In this project, I learned how to use Python's decision-making statements (`if`, `elif`, and `else`) by developing a **Grade Calculator**. The program accepts marks for five subjects, calculates the total and average, and determines the student's grade based on the average score.

---

## 📚 Topics Covered

- if Statement
- if...else Statement
- if...elif...else Statement
- Decision Making
- Comparison Operators
- User Input

---

## 💻 Project

### Grade Calculator

The program performs the following tasks:

- Accepts marks for five subjects
- Calculates the total marks
- Calculates the average marks
- Determines the grade based on the average
- Displays the appropriate result

---

## 🖥️ Sample Output

```
******** GRADE CALCULATOR ********

Enter Tamil Mark   : 90
Enter English Mark : 88
Enter Maths Mark   : 95
Enter Science Mark : 91
Enter Social Mark  : 89

Total   : 453
Average : 90.6

Congratulations! Your Grade is A
```
