# 🚀 Day 7 – Student Management System

## 📌 Overview

This is my Day 7 mini project as part of my #100DaysOfAI learning journey.

I developed a simple Student Management System using Python. The project combines the Python fundamentals I learned during Week 1, including variables, user input, conditional statements, loops, and functions.

## 💻 Project Features

The program provides a simple menu with three options:

1. Add Student
2. Display Student
3. Exit

### Add Student

The program accepts:

- Student Name
- Student Age
- Student Department

### Display Student

Displays the stored student information.

### Exit

Allows the user to safely exit the program.

- Type Casting
