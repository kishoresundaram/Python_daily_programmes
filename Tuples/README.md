# 🚀 Day 9 – Employee Records Using Tuples

## 📌 Overview

This is my Day 9 mini project as part of my **#100DaysOfAI learning journey**.

I built a simple Employee Records program using **Python Tuples** to store and display structured employee information.

The project demonstrates how multiple tuples can be combined into a collection and processed using a `for` loop.

## 💻 Project Features

The program:

* Stores employee information using tuples
* Combines multiple employee tuples into one collection
* Displays employee records using a `for` loop
* Counts the total number of employees using `len()`
* Uses tuple unpacking to access individual values

## 📚 Concepts Used

* Python Tuples
* Nested Tuples
* Tuple Unpacking
* `for` Loop
* `len()` Function
* Structured Data
* Variables
