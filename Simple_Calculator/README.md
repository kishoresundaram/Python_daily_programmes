# 🚀 Day 3 – Python Operators

## 📌 Overview

This is my **Day 3** project as part of my **#100DaysOfAI** learning journey.

In this project, I learned how different operators work in Python by building a **Simple Calculator**. The program accepts two numbers from the user and performs various arithmetic operations.

---

## 📚 Topics Covered

- Arithmetic Operators (`+`, `-`, `*`, `/`, `//`, `%`, `**`)
- Assignment Operators
- Comparison Operators
- Logical Operators
- User Input
- Basic Mathematical Calculations

---

## 💻 Project

### Simple Calculator

The program performs the following operations:

- Addition
- Subtraction
- Multiplication
- Division
- Floor Division
- Modulus
- Power
