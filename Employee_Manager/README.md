# 🚀 Day 11 – Employee Information Manager

## 📌 Overview

This is my Day 11 mini project as part of my **#100DaysOfAI learning journey**.

I built a simple menu-driven **Employee Information Manager using Python Dictionaries**. The program allows users to display employee information, update salary details, and manage employee skills.

## 💻 Project Features

The program provides five options:

1. Display Employee
2. Update Salary
3. Add Skill
4. Display Skills
5. Exit

### Display Employee

Displays employee information using dictionary key-value pairs.

### Update Salary

Allows the user to update the employee's salary directly in the dictionary.

### Add Skill

Allows users to enter one or multiple skills separated by commas.

### Display Skills

Displays all unique employee skills using a Set.

### Exit

Closes the application.
