# 🚀 Day 8 – Student List Manager

## 📌 Overview

This is my Day 8 project as part of my **#100DaysOfAI learning journey**.

I built a menu-driven **Student List Manager using Python** to practice Python Lists and understand how collections can be used to store and manage multiple values.

## 💻 Project Features

The program provides five options:

1. Add Student
2. Display Students
3. Remove Student
4. Show Number of Students
5. Exit

### Add Student

Allows the user to add a student name to the list.

### Display Students

Displays all students currently stored in the list.

### Remove Student

Allows the user to remove a student from the list.

### Show Number of Students

Displays the total number of students using Python's `len()` function.

### Exit

Closes the application.
