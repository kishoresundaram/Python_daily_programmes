## 💻 Project

### BMI Calculator

The program performs the following tasks:

- Accepts the user's name
- Accepts weight (in kg)
- Accepts height (in meters)
- Calculates BMI using the formula:
  
  **BMI = Weight / (Height × Height)**

- Displays the BMI using a function

---

## 🖥️ Sample Output

```
Enter Your Name : Kishore
Enter Weight (kg): 70
Enter Height (m): 1.75

Hello Kishore
Your BMI is: 22.86
```
