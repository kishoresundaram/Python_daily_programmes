# 🚀 Day 2 – Python Data Types & Type Casting

## 📌 Overview

This is my **Day 2** project as part of my **#100DaysOfAI** learning journey.

In this project, I learned about Python data types and type casting by developing a simple **Age Calculator**. The program accepts the user's name and birth year, calculates the current age, and displays the output in a structured format.

---

## 📚 Topics Covered

- Data Types
- Integer (`int`)
- Float (`float`)
- String (`str`)
- Boolean (`bool`)
- Type Casting
- `type()` Function

---

## 💻 Project

### Simple Age Calculator

The program performs the following tasks:

- Accepts the user's name
- Accepts the user's birth year
- Calculates the current age
- Displays the user details
- Displays the data type of each value

---

## 🖥️ Sample Output

```
**** Simple Age Calculator ****

Enter your name: Kishore
Enter your birth year: 2003

------ Age Calculator ------

Name       : Kishore
Birth Year : 2003
Age        : 23 Years

Data Types
Name       : <class 'str'>
Birth Year : <class 'int'>
Age        : <class 'int'>
```
